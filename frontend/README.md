# Mini Orchestrator console

React + TypeScript operator console for the Mini Orchestrator control plane.
See the repository root `README.md` and `docs/DEVELOPMENT.md` for setup.

```bash
npm ci
npm run dev        # http://localhost:5173, talks to VITE_ORCHESTRATOR_URL (default http://127.0.0.1:8080)
npm run lint
npm run typecheck
npm test
npm run build
```
